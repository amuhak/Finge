A RESEARCH PARTNER, WITH A PAPER TRAIL

Three tools. One research workflow.

01

Cursor builds the companion

Use the repository’s Cursor rules to extend artifact adapters and tests without changing FishCast’s models.

02

Grok API explains the evidence

The assistant receives normalized results and source references. Numeric comparisons stay in application code. Connect XAI_API_KEY on the server to enable it.

03

GrokBot operates the research routine

Give the actual GrokBot application the runbook in docs/AGENT_WORKFLOW.md: open Finge, import results, compare tracks and export a brief. This is a documented handoff, not an embedded GrokBot connection.

Built here with Codex. Cursor and GrokBot usage must be demonstrated in those products; this screen does not claim they have already been used.
